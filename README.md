# achilles-uptime

Внешний мониторинг доступности analytics.achilles.bz.

GitHub Actions проверяет сайт каждые 5 минут (3 попытки с паузой 10 секунд).
При недоступности шлёт алерт в Telegram, при восстановлении - отбой,
пока сайт лежит - напоминание каждые 30 минут.

Секреты репозитория: `UPTIME_TG_BOT_TOKEN`, `UPTIME_TG_CHAT_ID`.

Примечание: GitHub отключает scheduled-workflow после 60 дней без коммитов
в репозитории - при получении такого письма достаточно сделать любой коммит
или нажать Run workflow вручную.
